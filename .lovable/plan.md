# Галерея великих математиков (Античность)

Сайт-галерея с тремя античными математиками: Фалес, Пифагор, Евклид. Главная страница-витрина, три персональные страницы, общая навигация и античная эстетика.

## Структура сайта

### Маршруты
- `/` — Главная (витрина с тремя карточками)
- `/thales` — Фалес Милетский
- `/pythagoras` — Пифагор Самосский
- `/euclid` — Евклид Александрийский
- `/about` — О проекте
- `/sources` — Источники

### Общий каркас (на каждой странице)
- **Шапка**: заголовок «Галерея великих математиков», подзаголовок «Античность: Фалес, Пифагор, Евклид».
- **Меню**: Главная · Фалес · Пифагор · Евклид · О проекте · Источники.
- **Подвал**: «Индивидуальный проект студента группы ИР1-25 Ермакова Р. А., Чебоксарский электромеханический колледж, 2026» + ссылка на «Источники».

## 1. Главная страница

- Hero-блок: крупный заголовок «Галерея великих математиков», подзаголовок про античность, короткое вступление (1–2 строки).
- Сетка из трёх карточек (3 колонки на десктопе, 1 колонка на мобильном):
  - Портрет в едином формате (одинаковые пропорции, рамка под мрамор/пергамент).
  - Имя крупно: «Фалес Милетский» / «Пифагор Самосский» / «Евклид Александрийский».
  - Годы жизни мелким шрифтом.
  - Краткая характеристика (1–2 предложения, цепляющие):
    - Фалес: «Первый, кто начал доказывать геометрические теоремы. Измерил высоту пирамиды по тени.»
    - Пифагор: «Превратил математику в религию и доказал, что всё есть число. Его теорему знает каждый школьник.»
    - Евклид: «Собрал знания предшественников в "Начала" — учебник, переживший две тысячи лет. "В геометрии нет царских дорог".»
  - Кнопка «Подробнее» → персональная страница.
- Hover-эффект: лёгкий подъём карточки и подсветка рамки.

## 2. Персональные страницы (3 шт., единый шаблон)

Структура каждой страницы сверху вниз:

1. **Заголовок**: имя + годы жизни + место деятельности.
2. **Портрет** слева, краткое лид-описание справа (на мобильном — друг под другом).
3. **Биографическая справка** — связный текст 2–4 абзаца (происхождение, путешествия, ключевые события, школа/окружение).
4. **Ключевые открытия** — список карточек/блоков с заголовком и пояснением; формулы рендерятся читаемо (например, `a² + b² = c²`, `√2`, `2^(p−1)·(2^p − 1)`).
5. **Хронологическая таблица** — единый компонент на всех трёх страницах с подсветкой текущего математика (чтобы видеть эпоху и контекст).
6. **Блок «Легенда / Интересный факт»** — выделенная цитатная плашка с иконкой свитка.
7. **Цитата** — крупная типографика с засечками, кавычки-«ёлочки», атрибуция.
8. **Навигация снизу**: «← Предыдущий математик» / «Следующий математик →».

Контент по карточкам берётся дословно из брифа пользователя (Фалес — теоремы о диаметре, вертикальных углах, измерение пирамиды, легенда о колодце и затмении 585 г. до н. э., надпись на статуе; Пифагор — теорема, музыкальные интервалы 2:1, 3:2, 4:3, гармония сфер, иррациональность √2, легенда о щенке, «Всё есть число»; Евклид — «Начала», аксиоматический метод, пятый постулат, алгоритм Евклида, бесконечность простых, совершенные числа, легенда о Птолемее и трёх оболах, «В геометрии нет царских дорог»).

## 3. Дополнительные страницы

- **О проекте**: цель серии портретов, что первая часть — античность, упоминание планов (Архимед, Диофант, Гипатия).
- **Источники**: оформленный список (нумерованный), с возможностью добавить ссылки позже.

## 4. Визуальное оформление

- **Палитра** (античная, пастельная, без вычурности):
  - Фон: тёплый «пергамент» / светлый мрамор.
  - Акцент: глубокий терракотовый или оливково-золотой.
  - Текст: тёмный графит.
- **Типографика**: шрифт с засечками для заголовков и цитат (например, Cormorant Garamond / Playfair Display), гротеск для UI/подписей (Inter).
- **Декор**: тонкие разделители в виде греческого меандра, иконки колонн/свитков в ключевых блоках, мягкие тени.
- **Портреты**: единые пропорции, лёгкая сепия/тонировка для общей гаммы, рамка под камень.
- **Адаптивность**: 3 колонки → 1 колонка на мобильном; читабельные размеры шрифтов; меню сворачивается в бургер.

- Структура файлов:

  - `src/components/MathematicianCard.tsx` — карточка для главной.
  - `src/components/Timeline.tsx` — хронологическая таблица с пропсом `highlight`.
  - `src/components/QuoteBlock.tsx`, `src/components/LegendBlock.tsx`, `src/components/DiscoveryItem.tsx`.
  - `src/data/mathematicians.ts` — единый источник данных (имя, годы, место, лид, биография, открытия, легенда, цитата, путь, портрет).
  - `src/pages/Home.tsx`, `src/pages/Mathematician.tsx` (универсальный шаблон по `slug`), `src/pages/About.tsx`, `src/pages/Sources.tsx`.
- Дизайн-токены: расширить `src/index.css` (HSL переменные для пергамента, терракоты, золота) и `tailwind.config.ts` (семантические цвета, шрифты с засечками через `fontFamily`).
- Портреты: пока используем плейсхолдеры (`/placeholder.svg`) с подписями, какой именно рисунок (1.1 Мейер, 1.2 бюст, 1.3 статуя) — пользователь сможет заменить файлы позже, положив их в `public/portraits/`.
- Формулы — обычная типографика с Unicode (²·√·−·…), без подключения KaTeX, чтобы не утяжелять.
- Вся вёрстка — Tailwind, компоненты shadcn/ui (Card, Button, Separator, Table).
